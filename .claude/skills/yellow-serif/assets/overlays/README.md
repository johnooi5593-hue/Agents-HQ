# Light-leak overlays (optional)

Drop clean light-leak or bokeh clips here (`.mp4`, `.mov`, `.webm`, `.m4v`: light on black, no watermark, no end card, clips you have the rights to). The render then uses pieces of them for the section transitions, screen-blended. With no clip here, it makes its own light leaks procedurally. Clips in this folder are not committed (see `.gitignore`).
