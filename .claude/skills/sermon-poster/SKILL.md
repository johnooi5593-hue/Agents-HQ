Own the sermon title artwork and its editable handoff. The default deliverable is four independent 3840 x 2160 originals. **When a reference image is supplied, reference-first fidelity is the default for all four**: four independent compositions that retain the reference's visual language, not four unrelated styles. Only use distinct Cinematic / Minimal / Energetic / Editorial styles when no visual reference is provided or the owner explicitly requests stylistic exploration. The current explicit brief overrides defaults. Full supplied titles take precedence over generic clip-cover word limits or all-caps rules. ## Reference-first design contract (default whenever a visual reference is supplied)

1. **Source reference is the primary art direction.** Inspect its actual design and preserve the overall composition logic, visual hierarchy, palette, textures, lighting, original visual motifs, typography *feeling*, scale relationships, negative space and atmosphere. Do not replace it with a generic preset, procedural background or a previously approved but unrelated service poster. Treat multiple references according to the user's specified priority; if unspecified, use the explicitly selected main reference.
2. **Do not confuse frozen words with frozen layout.** Lock the actual approved words and uploaded face/source assets for a generation revision, but allow dynamic layout, typography placement, masking, depth, color grading of the *surroundings*, and per-service speaker positioning. A `Same approved artwork` mode is opt-in only; it must not silently override an uploaded reference or service-specific speaker.
3. **Blend information into the artwork.** Chinese and English sermon titles, original speaker photo, speaker names in both languages, service name, date, time and venue (when supplied) must be composed according to the *reference's own* design language. Use an intentional hierarchy, integrated textures and lighting, suitable local contrast, accurate glyphs and natural edge treatment; avoid bolted-on rectangular detail boxes, generic bottom text strips, floating cutouts or a separate unrelated portrait column unless those are explicitly part of the reference.
4. **Identity and exact text are non-negotiable.** Preserve supplied speaker face pixels and recognizable likeness; prefer original photo compositing instead of regenerating or repainting the face. All requested Chinese/English lettering and numeric details must retain their exact characters and order. Position and visual styling can change; content cannot. Never bake an AI-generated guess of exact event text when an accurately typeset text layer can be used. Prevent double-rendered text.
5. **Check against the actual reference.** Before final delivery, view the reference and rendered image side by side. Reject and revise outputs that drift into a generic poster, omit/misspell details, place the speaker unnaturally, flatten visual style, or materially diverge from the reference. If input artwork is flattened and cannot be cleanly adapted or original lettering cannot be preserved, disclose that limit; never mark it as exact fidelity.

## Four separate editable designs

When a reference is supplied, all four independent options must feel unmistakably derived from that *same supplied reference*. Vary framing, whitespace, depth, title/portrait balance or other restrained composition decisions, while preserving its core typography treatment, palette, textures and visual motifs. Never force four unrelated house styles onto a reference-led brief. When no reference is available, the four creative directions below are the fallback. Keep every option independently editable and exportable.

- **Cinematic:** controlled light, depth and restrained premium hierarchy, grounded in the reference.
- **Minimal:** deliberate space, precise alignment and strong readable type.
- **Energetic:** purposeful movement, contrast and dynamic scale without visual clutter.
- **Editorial:** intentional composition, expressive type hierarchy and disciplined texture.

These are directions, not permission to invent subject matter. Preserve meaningful source elements and the same identities across all options. Generate background imagery separately from final titles where possible; prefer real vector Chinese and English text with licensed, actually available fonts. Verify glyph rendering and spacing, especially Chinese punctuation and long titles. If custom lettering is preserved as pixels, disclose that it is movable/scalable imagery rather than editable characters. A flat background/subject remains raster even inside an editable SVG or HTML project; do not promise a layered PSD.

Retain source uploads, owned assets, project JSON, layer positions/fonts and immutable revisions. Save revisions without overwriting earlier exports. Restoring history creates a new current version. Editing a title must also update the project title fields so export validation checks the intended wording.
