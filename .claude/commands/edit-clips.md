description: Edit every new clip in inbox/ in parallel, brand-check the results, and report
---
Edit the new clips in `inbox/`.

**Which clips.** If the arguments below name clips (for example `inbox/<file>` or `inbox/<channel>/<file>`, sent by the owner's Edit button), edit only those. Otherwise edit every waiting clip: `ls inbox` for the main channel (mp4, mov, m4v), and `ls inbox/<key>` for each channel folder (every folder in `inbox/` except radar, stats and messages; the channel names are in `.hq-channels.json`).

**Which package.** The arguments may carry a `Package:` line from the owner's Edit button: `video` (the edit only), `caption` (the edit and 3 title + caption sets) or `full` (the edit, 3 sets, then Codex thumbnails from the title the owner picks). No line means `full`. Write the word into `out/<name>/package.txt` (step 5); the app shows the video's card with just those steps.

**Which channel.** Every channel goes through exactly the same steps, skills and checks as the main channel; only its brand is its own. A clip in `inbox/<key>/` belongs to that channel. Every sub-agent for that clip gets this line in its prompt: "Channel: <name>. Same procedures as the main channel: follow "Brand rules" and "Lessons" as always, and read "<name> · Company" instead of "Company" and "<name> · Brand rules" on top (its rules win where they differ). Never use the main channel's name, logo, slogans or hashtags." Clips straight in `inbox/` are the main channel: no channel line.

1. Board: `node hq/tasks.js add "Edit <n> clips" --team Creative`, move it to doing. If the arguments name a New footage task, move that one to doing instead of adding a new task. A clip that has a New footage task on the board (`node hq/tasks.js list`) gets that task moved to doing too.
2. Start one **clip-editor** sub-agent per clip. Start them all in the same message so they work in parallel. Tell each one its file name (and its channel line). **Cover:** for package `video` or `caption` add the line "No cover: the owner did not ask for one. No cover.jpg." Otherwise read `hq/thumbnail-design/index.json` once; if its `defaults` has a template id for the clip's channel key (`""` for the main channel), that channel's covers come from Codex after the owner approves the video, so add the line "Cover: Codex makes it. No cover.jpg." to that clip's prompt. Without a default template (or no such file), the clip-editor makes `cover.jpg` as always.
3. When all of them are done, run the **brand-checker** on the new folders in `out/` (with the channel line for a channel's clips).
4. If the brand-checker flags something, send that clip back to a clip-editor with the exact fix, then check again. Repeat until every clip passes.
5. Move each passed raw clip: `mv inbox/<file> done/` (or `mv inbox/<key>/<file> done/`). For a channel's clip, write its key into the clip's work folder: `out/<name>/channel.txt` holding just the key (the posting screen uses it to pick that channel's accounts). Write the clip's package word (`video`, `caption` or `full`) into `out/<name>/package.txt`.
6. **Get it ready to post** (packages `caption` and `full`; skip for `video`). Start one **social-media-manager** sub-agent per passed clip (all in the same message, each with its channel line) for its posting pass: it writes `out/<name>/post.md` with the posting plan, exactly 3 title + caption + hashtag sets, and the TikTok text.
7. **One Review task per clip:** `node hq/tasks.js add "Review · <clip title>" --team Creative --status review --note "out:<name>"` (for a channel's clip, put `channel:<key>` in the note too). Never name it "Final": for a channel with a Codex template, the only Final is the task HQ creates when Codex returns the four covers; without a template, the app itself shows the task as "Final" once the video, cover and caption are all there. Then move the batch task and the clip's New footage task to done.
8. Report to the owner: a short table (clip, channel, package, edit length, platforms) and the paths. Tell the owner to open the video's card on the board, which walks through the package: approve the video, pick one of the 3 title + caption sets, then (full set) pick one of the Codex thumbnails made from that title. When the card shows **READY**, **Approve & post** posts the whole set to that channel's connected accounts. End with: "Nothing is published. Reply OK to approve."
